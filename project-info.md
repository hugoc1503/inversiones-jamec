# Ficha del proyecto — Inversiones JAMEC

## Versiones
- **Diseño visual:** [Framer](https://clear-hyacinth-933919.framer.app), desarrollado a partir de una plantilla y personalizado.
- **Implementación de código:** versión independiente creada con HTML5, CSS3 y JavaScript.

## Alcance actual
- Landing page adaptable a escritorio y móvil.
- Navegación responsive.
- Secciones de presentación, servicios, proceso, referencias visuales, preguntas frecuentes y contacto.
- Validación básica del formulario en el navegador.

## Transparencia
La versión programada es una reconstrucción propia inspirada en el propósito y la estructura del sitio de Framer; no es una exportación automática del proyecto Framer. El formulario actual no transmite ni almacena datos.
